Apple Messages reader (imessage-reader)
=======================================

This program reads Apple Messages, from a Mac's Messages database or from an
iPhone backup, for the Message Vault desktop app. The app starts it as a
separate program and reads its answers over a pipe. Nothing else in Message
Vault is part of this program.

What it contains
----------------

Besides its own code, this program links these libraries, all by Christopher
Sardegna and all under GPL-3.0-or-later:

  imessage-database  https://github.com/ReagentX/imessage-exporter
  crabstep           https://github.com/ReagentX/crabstep
  crabapple          https://github.com/ReagentX/crabapple

Parts of its own code, the decryption of encrypted iPhone backups and its
error type, are adapted from imessage-exporter by the same author, also
GPL-3.0-or-later. The source files say which parts. Copyright for the adapted
parts remains with the original author.
