# Demo seed data sources

## corpus/

`pride-and-prejudice.txt` — body text from Project Gutenberg ebook 1342
(Pride and Prejudice by Jane Austen), starting at the novel’s opening sentence.
Public domain in the US. The generator strips chapter headings and samples
sentence-sized spans for message bodies.

## names/

Curated first / middle / last name lists for procedural contacts (not a full
SSA dump). Treat as demo-only synthetic identity data.
