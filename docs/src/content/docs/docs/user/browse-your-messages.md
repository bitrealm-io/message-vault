---
title: Browse your messages
description: Open Conversations after the first import — the same website in the browser and the desktop app.
---

After Import finishes, open **Conversations** in the sidebar (browser at **http://localhost:8080** or the desktop app). Select a thread to read messages and view attachments.

Group chats appear in the same list as one-to-one threads. Search with `kind:group` when you only want multi-party conversations — [Search](/docs/user/how-to/search/).

## Sidebar

| Label | Meaning |
|-------|---------|
| **Conversations** | Message threads |
| **Contacts** | People and handles from imports |
| **Trash** | Soft-deleted items ([Trash](/docs/user/how-to/trash/)) |
| **Import** | Push a backup into Message Crate (desktop app only) |
| **Export** | Pull messages to disk (desktop app only) — [Export your messages](/docs/user/how-to/export-your-messages/) |
| **Settings** | Account, profile, storage, appearance |
| **Log out** | End the session (in the account menu, the circle at the top right) |

**Saved groups** under the sidebar store search queries. Create one with **+ New**, then click a name to run that search again — [Saved searches](/docs/user/how-to/saved-searches/).

Imports are tagged with a **source** (for example iMessage or WhatsApp). Search can limit results with `source:…`.
