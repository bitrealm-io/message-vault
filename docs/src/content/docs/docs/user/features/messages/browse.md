title: Browse messages
description: The conversation list and the left panel, which are the same in the browser and the desktop app.
---

**Messages** in the left panel lists every conversation, in the browser and in the desktop app alike. Selecting a conversation shows its messages and attachments.

Group chats appear in the same list as one-to-one threads. Search with `kind:group` when you only want multi-party conversations — [Search](/docs/user/features/messages/search/).

## Left panel

| Label | Meaning |
|-------|---------|
| **Messages** | Every conversation |
| **Contacts** | People and handles from imports |
| **Trash** | Soft-deleted items ([Trash](/docs/user/features/messages/trash/)) |
| **Import** | Push a backup into Message Crate (desktop app only) |
| **Export** | Pull messages to disk (desktop app only) — [Export your messages](/docs/user/features/messages/export/) |
| **Contact Groups** | Groups of contacts, with **Unknown** and **No group** |
| **Saved Searches** | Searches kept by name |
| **Message Tags** | Tags put on conversations, with **No tag** |

**Settings** and **Log out** are in the account menu, the round button at the top right.

**Saved Searches** store search queries. The **+** beside the heading creates one, and selecting a name runs that search again — [Saved searches](/docs/user/features/messages/saved-searches/).

Imports are tagged with a **source** (for example iMessage or WhatsApp). Search can limit results with `source:…`.
