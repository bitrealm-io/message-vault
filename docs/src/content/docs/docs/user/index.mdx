The User Guide takes a person from nothing installed to their own messages in a Message Crate they run themselves.

## Get started

[Get started](/docs/user/get-started/what-is-message-crate/) is eight numbered steps, read in order.
Steps 1 to 3 start a Message Crate and look at its demo data, and need only Docker and a browser.
Steps 4 to 8 put real messages into the same Message Crate from a phone backup.

Each step ends at something visible on screen, so a step that failed is easy to name.

## Other import sources

The numbered steps cover iPhone messages and Android SMS and MMS.
[Messages on a Mac](/docs/user/import-sources/mac-messages/), [WhatsApp](/docs/user/import-sources/whatsapp/), and [old backups](/docs/user/import-sources/old-backups/) from other tools each have a page of their own.

## Features

Features describes what each part of the product does, grouped the way the product is: Messages, Contacts, Settings, and Owner.
The pages stand alone and can be read in any order.
