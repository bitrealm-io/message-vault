This is the User Guide. These pages explain how to run a vault, import phone backups, and browse messages on a machine you control.

## Get started

If the goal is to use Message Vault, start with [What is Message Vault?](/docs/user/get-started/what-is-message-vault/). That chapter, then Prepare a backup and Import, is the path for a first archive.

## Developer

If the goal is to compile the project, run Docker Compose, call the HTTP API, or read file-format tables, use the [Developer](/docs/developer/) docs.
