---
title: Prepare a backup
description: Choose the backup path for your phone, then import it with the desktop app.
---

The desktop app **Import** screen reads a file or folder you already have on the computer. Pick the guide that matches the phone and app:

- [iPhone or iPad (Messages)](/docs/user/prepare-a-backup/iphone-ipad/)
- [WhatsApp on iPhone](/docs/user/prepare-a-backup/iphone-whatsapp/)
- [SMS and MMS on Android](/docs/user/prepare-a-backup/android-sms/)
- [WhatsApp on Android](/docs/user/prepare-a-backup/android-whatsapp/)

GO SMS Pro, iMazing, OpenExtract, and SMS Backup+ are [rescue imports](/docs/user/how-to/rescue-imports/) for files you already have. Prefer the four paths above when you can still make a new backup.

Why the files come from the device: [Why you provide backups](/docs/user/get-started/why-you-provide-backups/).
